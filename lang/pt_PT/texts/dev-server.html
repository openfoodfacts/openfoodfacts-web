Core Backend, APIs & Data Engine

The server team powers the heart of Open Food Facts: our high-throughput read/write APIs, complex scientific calculations (Nutri-Score, NOVA, Green-Score), taxonomy ontologies, search services, and daily open database dumps.

🐪

Product-Opener (Server Core)

Perl MongoDB Taxonomies Calculations

Product-Opener is the primary database and web application powering Open Food Facts. It handles product histories, user accounts, image uploads, and algorithmic score calculations.

  • Official computational reference for Nutri-Score, NOVA groups, and Eco-Score / Green-Score
  • Global multilingual taxonomies translating millions of ingredient synonyms and food categories
  • Extensive test suites ensuring backward compatibility and calculation precision

Search-a-licious Search Engine

Python Elasticsearch Faceted Search

A pluggable, high-performance search service designed to search millions of products in milliseconds with complex filter combinations, facets, and fuzzy matching.

  • Multi-lingual full-text queries across ingredients, brands, and categories
  • Fast facet aggregation for nutritional ranges and eco-attributes
  • Pluggable architecture allowing different search backends

Bulk Exports & Query Pipeline

PostgreSQL Parquet / CSV Python

We believe in open access. We maintain automated daily pipelines extracting MongoDB data into relational PostgreSQL tables and publishing multi-gigabyte open data dumps.

  • Daily JSONL, CSV, and compressed Parquet dumps on world.openfoodfacts.org/data
  • openfoodfacts-query for mirroring key collections into relational schemas
  • Free for researchers, NGOs, developers, and the global public commons
