Ekosystem för frontend & JavaScript

Vi bygger en responsiv och tillgänglig webbupplevelse som är ett nöje att använda. Från nästa generations frontend till gemensamma webbkomponenter och specialiserade mikroappar – JavaScript- och TypeScript-utvecklare formar hur miljontals medborgare utforskar och kontrollerar livsmedelsdata varje dag.

Nästa generations flaggskepp
🚀

Open Food Facts Explorer

SvelteKit Tailwind CSS TypeScript Vite

Explorer är Open Food Facts nya flaggskepp bland webbgränssnitten. Det förnyar hela webbupplevelsen med blixtsnabba sidbyten, integration med ett modernt designsystem, responsiv produktutforskning och genomgående tillgänglighet.

  • Fullständig rendering på serversidan & reaktivitet på klientsidan med SvelteKit
  • Designsystem i Tailwind CSS framtaget tillsammans med vårt designteam i Figma
  • Tillgängligt, internationaliserat gränssnitt för över 80 språkområden
  • Testversion tillgänglig för direkt testning på beta.openfoodfacts.net
Testa demoversionen (beta) Kodarkivet explorer #explorer på Slack

Bibliotek med webbkomponenter

Lit TypeScript Web Components NPM

Ramverksoberoende gränssnittselement publicerade på NPM. De möjliggör återanvändbara bidragsgränssnitt i våra äldre servermallar, det moderna Explorer-gränssnittet, Hunger Games och externa partnerportaler.

  • Nutri-Sight: OCR-extrahering & visuell kontroll av näringsdeklarationer
  • AI-frågor från Robotoff & widgetar för validering med mänsklig medverkan
  • Stavningskontroll av ingredienser, visning av kunskapspaneler och fotoverktyg
  • Kan bäddas in överallt utan inlåsning i ett ramverk

Webbappen Open Prices

Vue.js 3 TypeScript Tailwind CSS PWA

En öppen, gemensamt uppbyggd databas och progressiv webbapp för att följa matpriser, livsmedelsinflation och pristransparens hos livsmedelskedjor världen över.

  • Streckkodsskanning, uppladdning av kvittofoton och geografisk lokalisering av butiker
  • Dynamiska prisjämförelser mellan återförsäljare och datum
  • Fungerar tillsammans med Open Prices Python-backend
prices.openfoodfacts.org Kodarkiv på GitHub #prices

SDK för JavaScript & Node.js

Node.js TypeScript Edge-miljöer & webbläsare

Den officiella klient-SDK:n för JavaScript- och TypeScript-utvecklare. Ger fullständig, typad åtkomst till Open Food Facts produktdata, sök-API:er, fasetter och skrivslutpunkter för bidrag.

  • Fullständiga TypeScript-typdefinitioner för produkter, Nutri-Score, allergener och märkningar
  • Stöder Node.js, Cloudflare Workers, Deno, Bun och webbläsarmiljöer
  • Används i interna webbverktyg, Node-skript och gemenskapens återanvändningsprojekt

Nutripatrols modereringsgränssnitt

React TypeScript Moderering

Nutripatrol är plattformen som skyddar Open Food Facts datakvalitet. Gränssnittet ger moderatorer snabba arbetsflöden för att granska misstänkta ändringar, bekämpa skadegörelse och undersöka avvikelser i data.

  • Jämförelse av versioner sida vid sida och uppföljning av bidragsgivares anseende
  • Modereringsåtgärder i grupp för att snabbt godkänna eller återställa ändringar
Kodarkiv på GitHub

Gränssnitt för Folksonomy Engine

JavaScript Öppna metadata Nyckel–värde

Precis som OpenStreetMaps taggmodell eller Wikidatas egenskaper gör Folksonomy det möjligt att lägga till valfria metadatataggar som nyckel–värde-par för livsmedel (t.ex. organ för halalcertifiering, förpackningsmått och särskilda påståenden).

  • Dynamisk egenskapsredigerare och sökgränssnitt
  • Utbyggbar datamodell som är frikopplad från fasta scheman
