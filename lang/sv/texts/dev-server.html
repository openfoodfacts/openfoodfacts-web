Intelligensen bakom Open Food Facts-apparna och API:t

Open Food Facts samlar in data med hjälp av ett WRITE API, bearbetar det och gör det tillgängligt med hjälp av ett READ API och en webbversion. Beräkna Nutri-Score, NOVA-grupper, extrahera tillsatser, oavsett språk, synonymer eller eventuella stavfel. Detta är bara en liten del av de områden som serverteamet arbetar med för att säkerställa global transparens kring livsmedel.

Bidra till kärnan med Perl

Vill du lära dig ett nytt språk? Servern är huvudsakligen kodad i Perl. Oavsett om du är en erfaren Perl-entusiast eller bara har provat Perl för systemadministration finns det en bugg på lagom nivå och handledare som kan vägleda dig. Och också mer än ett sätt att göra det på ;-)

Skapa användbara verktyg på alla språk

HungerGames är ett exempel på ett litet spel skrivet i React som gör positiv skillnad för Open Food Facts. LanguageSwitcher, ett annat verktyg, är kodat i Python. Ditt verktyg, ditt språk (undvik helst assembler ;-)

Anslut till oss på Slack och GitHub

Vi synkroniserar på Slack och GitHub. Delta i samtalet på Open Food Facts-arbetsytan i Slack (du kan bjuda in dig själv) och i kodförrådet openfoodfacts-server på GitHub.
