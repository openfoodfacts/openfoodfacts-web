Product-Opener (serverkärnan)

Perl MongoDB Taxonomier Beräkningar

Product-Opener är den huvudsakliga databas- och webbapplikationen bakom Open Food Facts. Den hanterar produkthistorik, användarkonton, bilduppladdningar och algoritmisk betygsberäkning.

  • Officiell beräkningsreferens för Nutri-Score, NOVA-grupper och Eco-Score/Green-Score
  • Globala, flerspråkiga taxonomier som översätter miljontals ingredienssynonymer och livsmedelskategorier
  • Omfattande testsviter som säkerställer bakåtkompatibilitet och korrekta beräkningar

Sökmotorn Search-a-licious

Python Elasticsearch Fasettsökning

En utbytbar söktjänst med hög prestanda, utformad för att söka bland miljontals produkter på millisekunder med komplexa filterkombinationer, fasetter och ungefärlig matchning.

  • Flerspråkiga fulltextsökningar i ingredienser, varumärken och kategorier
  • Snabb fasettaggregering för näringsintervall och miljöegenskaper
  • Modulär arkitektur som gör det möjligt att använda olika sökmotorer i bakgrunden

REST-API:er och OpenAPI-specifikation

OpenAPI 3.0 JSON Schema Kunskapspaneler

Våra offentliga API:er hanterar över 100 miljoner förfrågningar varje månad från mobilappar, forskare, hälsoorganisationer och tusentals kommersiella vidareanvändare.

  • API v3 med strukturerade slutpunkter för att söka efter, lägga till och uppdatera produkter
  • Knowledge Panels API med kortbaserade förklaringar av informationens innebörd
  • Omfattande dokumentation baserad på OpenAPI-standarder

Masexporter & bearbetning av frågor

PostgreSQL Parquet / CSV Python

Vi tror på öppen tillgång. Vi underhåller automatiserade flöden som dagligen hämtar data från MongoDB till relationstabeller i PostgreSQL och publicerar öppna datautdrag på flera gigabyte.

  • Dagliga datautdrag i JSONL, CSV och komprimerat Parquet-format på world.openfoodfacts.org/data
  • openfoodfacts-query för att spegla centrala samlingar i relationsdatabasscheman
  • Fritt tillgängligt för forskare, ideella organisationer, utvecklare och allmänheten världen över
