Open Products Facts data exports

Database dumps and exports are generated nightly. The database is very big, so you can find different ways to use the data, depending on the export flavor.

Informacije o različitim poljima za MongoDB dump i CSV izvoze dostupne su na https://world.openproductsfacts.org/data/data-fields.txt

MongoDB dump

Podaci za sve proizvode dostupni su u dumpu MongoDB baze podataka.

Poveznica
https://static.openproductsfacts.org/data/openproductsfacts-mongodbdump.gz
sha256sum

Delta Export

Daily delta exports are provided for the previous 14 days. Popis trenutno dostupnih delta datoteka može se pronaći na https://static.openproductsfacts.org/data/delta/index.txt.

Svaki redak predstavlja datoteku koja je dostupna na https://static.openproductsfacts.org/data/delta/{filename}.

The filename contains UNIX timestamp of the first and the last change contained in the JSON file, so that the delta files can be imported (after extraction) with mongoimport in alphabetical order.

Please note that due to the nature of mongoexport, the delta files cannot tell you about deleted products. Da biste uklonili izbrisane proizvode iz svoje baze podataka, morat ćete uvesti cjeloviti MongoDB dump.

JSONL data export

The whole database is also available in JSONL format (sometimes called LDJSON or NDJSON) where each line is a JSON object. It represents the same data as the MongoDB export. Datoteka je komprimirana pomoću gzip-a.

Poveznica
https://static.openproductsfacts.org/data/openproductsfacts-products.jsonl.gz

Pogodan način iskorištavanja baze podataka je korištenje DuckDB-a, analitičkog alata u procesu dizajniranog za obradu velikih količina podataka u djeliću sekunde. You can read our blog post where we walk you through exploring and processing the Open Products Facts database with DuckDB

Izvoz podataka za parkete na Hugging Faceu

Pojednostavljena verzija JSONL dumpa također je dostupna u Parquet formatu. During the conversion, we filtered columns that contains duplicated information, are used for internal debugging, or are simply irrelevant for users.

Parquet format se pokazao praktičnim:

  • Podaci su organizirani po stupcima, a ne po redovima, što štedi prostor za pohranu i ubrzava analitičke upite, tj. možete odabrati samo one stupce koji su vam važni, optimizirajući izvedbu upita, čak i na računalima početne razine.
  • Highly efficient data compression and decompression, making it good for storing and sharing big datasets of any kind,
  • Supports complex data types and advanced nested data structures.

The dataset is available on Hugging Face, a collaborative Machine Learning ecosystem where developers and researchers can share models and datasets.

Poveznica
https://huggingface.co/datasets/openfoodfacts/product-database/resolve/main/food.parquet?download=true

Find more information in the Wiki, including guidelines for data reuse and example queries to get started.

Izvoz CSV podataka

Data for all products, or some of the products, can be downloaded in the CSV format (readable with LibreOffice, Excel and many other spreadsheet software) through the advanced search form.

Poveznice
https://static.openproductsfacts.org/data/en.openproductsfacts.org.products.csv.gz (compressed CSV in GZIP format: ~ 0.9 Gb, uncompressed: ~ 9 Gb)

The file encoding is Unicode UTF-8. The character that separates fields is <tab> (tabulation).

Izvoz RDF podataka

The database is also available in the RDF format. You can read the announcement in French.

OpenAPI Documentation for the JSON API

JSON API je također dostupan za čitanje podataka o proizvodu. This API is in particular used in the Open Products Facts mobile app for iPhone and Android.

S vremenom poboljšavamo API, ali pazimo da zadržimo kompatibilnost unatrag. Please get in touch if you use it, so that we can tell you about potential changes.

If you are unsure about anything, or have any question (there is no silly question), feel free to ask it on Slack :-)

Primjer: https://world.openproductsfacts.org/api/v3/product/737628064502.json

Note that if the output is too overwhelming, you can filter it - as described in the API documentation.

  • API V3 - new OpenAPI documentation - Work in Progress

OpenAPI help wanted

We're eager to finish the documentation of the API, add use-cases, and automate SDK generation. If you are an OpenAPI connoisseur, you are very welcome to help.

You are very welcome to use the API for production cases, as long as 1 API call = 1 real scan by a user. Any attempt to scrape the database using the API will very likely be blocked, as full daily exports are available on this very page.

Also, sending an HTTP header with your API call is a good way we can get in touch, should any issue arise.

Ako niste sigurni u bilo što ili imate pitanje (nema glupih pitanja), slobodno ga postavite na kanalu #api na Slacku :-)

Omotači i SDK-ovi

Vjerojatno imamo omotač za vaš omiljeni programski jezik. Ako to učinimo, možeš ga koristiti i poboljšati. Ako to ne učinimo, možete pomoći u njegovom stvaranju.

Omogućit će vam konzumaciju podataka, kao i korisnicima da doprinose novim podacima.

Opća načela za zadovoljstvo vaših korisnika

  • Možete pretraživati informacije o proizvodima, uključujući mnoge korisne izračunate vrijednosti.
  • DART: GitHub (Open Food Facts only at the moment)
  • Također možete implementirati cjelokupan tijek tako da odmah dobiju rezultat uz određeni napor s njihove strane.

Ako vaši korisnici ne očekuju rezultat odmah (npr. aplikacije za inventar)

  • Pošaljite fotografije (prednja strana/nutritivna vrijednost/sastojci): najmanje bolno za vaše korisnike
  • The Open Products Facts AI - Robotoff - will generate some derived data from the photos
  • Over time, other apps, and the Open Products Facts community will fill the data gaps

Ako vaši korisnici očekuju rezultat odmah (npr. aplikacije za prehranu ili alergije)

  • Submit ingredients + category > get Ingredient analysis, additives, allergens, normalized ingredients, vegan, vegetarian…
  • Submit labels for added value
  • Pošalji prehranu

Android/iPhone/Flutter mobile app

The code for the Open Products Facts mobile app is available on GitHub (Flutter, Kotlin Android and Swift iOS).

We look to turn the deprecated Kotlin and Swift codebases into Kotlin and Swift SDKs, help welcome :-)

Aplikacija omogućuje korisnicima skeniranje barkoda proizvoda, pregledavanje informacija o proizvodima te slanje fotografija i podataka za proizvode koji nedostaju.

Slobodno ponovno koristite kod (otvoreni je kod) i pomozite nam da ga poboljšamo za sve na cijelom planetu.
