Frontend & JavaScript Ecosystem

Open Food Facts Explorer

SvelteKit Tailwind CSS TypeScript Vite

Explorer is the new flagship frontend for Open Food Facts. It reimagines the entire web experience with lightning-fast page transitions, modern design system integration, responsive product explorations, and deep accessibility.

  • Full server-side rendering & client-side reactivity via SvelteKit
  • Tailwind CSS design system crafted with our design team in Figma
  • Accessible, internationalized UI ready for 80+ locales
  • Staging deployment ready for live testing at beta.openfoodfacts.net
Live Demo (Beta) explorer Repo #explorer on Slack

Web Components Library

Lit TypeScript Web Components NPM

Framework-agnostic UI elements published on NPM. They enable reusable contribution interfaces across our legacy server templates, modern Explorer frontend, Hunger Games, and third-party partner portals.

  • Nutri-Sight nutrition table OCR extraction & visual verification
  • Robotoff AI questions & human-in-the-loop validation widgets
  • Ingredients spellchecker, knowledge panel displays, and photo tools
  • Embeddable everywhere without framework lock-in

Open Prices Web App

Vue.js 3 TypeScript Tailwind CSS PWA

An open, crowdsourced database and progressive web app to track grocery prices, food inflation, and price transparency across supermarket chains worldwide.

  • Barcode scanning, receipt photograph upload, and store geolocation
  • Dynamic price comparisons across retailers and dates
  • Works in conjunction with the Open Prices Python backend
prices.openfoodfacts.org GitHub Repo #prices

JavaScript & Node.js SDK

Node.js TypeScript Edge & Browser

The official client SDK for JavaScript and TypeScript developers. Provides complete, typed access to Open Food Facts product data, search APIs, facets, and contribution write endpoints.

  • Full TypeScript typings for products, Nutri-Score, allergens, and labels
  • Supports Node.js, Cloudflare Workers, Deno, Bun, and browser environments
  • Powers internal web tools, Node scripts, and community reuses
NPM Package GitHub Repo

Nutripatrol Moderation UI

React TypeScript Moderation

Nutripatrol is the guardian platform for Open Food Facts data quality. The frontend provides moderators with high-speed workflows to review suspicious edits, combat vandalism, and audit data anomalies.

  • Side-by-side revision diffs and contributor reputation tracking
  • Batch moderation actions to approve or revert edits quickly
GitHub Repo
🏷️

Folksonomy Engine UI

JavaScript Open Metadata Key-Value

Similar to OpenStreetMap's tag model or Wikidata's properties, Folksonomy allows arbitrary key-value metadata tags on food items (e.g. halal certification bodies, packaging dimensions, specific claims).

  • Dynamic property editor and search interface
  • Extensible data model decoupled from fixed schemas
