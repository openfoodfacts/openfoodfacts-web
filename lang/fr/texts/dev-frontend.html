De notre frontend de nouvelle génération aux composants web partagés et aux micro-applications spécialisées, les développeurs JavaScript et TypeScript façonnent la manière dont des millions de citoyens explorent et vérifient quotidiennement les données alimentaires.

Ouvrir l'explorateur de faits alimentaires

SvelteKit Tailwind CSS TypeScript Vite

Explorer est le nouveau frontend phare d'Open Food Facts. Il réinvente l'expérience web dans son ensemble avec des transitions de pages ultra-rapides, une intégration moderne du système de design, des explorations de produits réactives et une accessibilité approfondie.

  • Rendu côté serveur complet & réactivité côté client via SvelteKit
  • Système de design Tailwind CSS conçu avec notre équipe design sur Figma
  • Interface utilisateur accessible et internationalisée, prête pour plus de 80 langues
  • Déploiement de staging prêt pour des tests en direct sur beta.openfoodfacts.net

Bibliothèque de composants web

Lit TypeScript Web Components NPM

Éléments d'interface utilisateur agnostiques vis-à-vis des frameworks, publiés sur NPM. Ils permettent des interfaces de contribution réutilisables à travers nos modèles de serveur hérités, le frontend moderne Explorer, Hunger Games et les portails de partenaires tiers.

  • Extraction OCR du tableau nutritionnel Nutri-Sight & vérification visuelle
  • Questions IA Robotoff & widgets de validation humaine (human-in-the-loop)
  • Correcteur orthographique d'ingrédients, affichages de panneaux de connaissances et outils photo
  • Intégrable partout sans dépendance à un framework spécifique

Application web Open Prices

Vue.js 3 TypeScript Tailwind CSS PWA

Une base de données ouverte et participative ainsi qu'une application web progressive pour suivre les prix des produits alimentaires, l'inflation alimentaire et la transparence des prix dans les chaînes de supermarchés du monde entier.

  • Scan de codes-barres, téléchargement de photos de tickets de caisse et géolocalisation des magasins
  • Comparaisons de prix dynamiques entre les détaillants et les dates
  • Fonctionne conjointement avec le backend Python Open Prices
prices.openfoodfacts.org Dépôt GitHub #prices

SDK JavaScript & Node.js

Node.js TypeScript Edge & Navigateur

Le SDK client officiel pour les développeurs JavaScript et TypeScript. Fournit un accès complet et typé aux données produits d'Open Food Facts, aux API de recherche, aux facettes et aux points de terminaison d'écriture pour les contributions.

  • Typages TypeScript complets pour les produits, le Nutri-Score, les allergènes et les labels
  • Prend en charge Node.js, Cloudflare Workers, Deno, Bun et les environnements de navigateur
  • Alimente les outils web internes, les scripts Node et les réutilisations par la communauté
Package NPM Dépôt GitHub

Interface de modération Nutripatrol

React TypeScript Modération

Nutripatrol est la plateforme gardienne de la qualité des données d'Open Food Facts. L'interface fournit aux modérateurs des flux de travail rapides pour examiner les modifications suspectes, lutter contre le vandalisme et auditer les anomalies de données.

  • Comparaisons côte à côte des révisions et suivi de la réputation des contributeurs
  • Actions de modération par lots pour approuver ou annuler rapidement les modifications
Dépôt GitHub

Interface du moteur de folksonomie

JavaScript Open Metadata Clé-Valeur

Similaire au modèle de tags d'OpenStreetMap ou aux propriétés de Wikidata, la Folksonomie permet d'ajouter des métadonnées arbitraires sous forme de clés-valeurs sur les produits alimentaires (par exemple : organismes de certification halal, dimensions de l'emballage, allégations spécifiques).

  • Éditeur de propriétés dynamique et interface de recherche
  • Modèle de données extensible découplé des schémas fixes
