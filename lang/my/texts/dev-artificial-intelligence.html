Robotoff Prediction Engine

Python FastAPI PyTorch Active Learning

Robotoff is the central brain analyzing packaging photos. Depending on confidence thresholds, it either applies updates automatically or generates interactive questions for human validation via Hunger Games and our mobile apps.

  • Real-time and batch prediction pipelines in Python & FastAPI
  • Feeds validated annotations back into training sets for continuous model improvement
  • Exposes prediction & question endpoints used by webcomponents and apps

Computer Vision & Logos

YOLO Object Detection ResNet

Our vision algorithms crop and identify logos, quality labels (Organic, Fair Trade, Halal, Kosher), Nutri-Score marks, and recycling symbols across imperfect, real-world photos.

  • Automatic detection of hundreds of label categories and certifications
  • Logo clustering to discover new brands and packaging emblems

Nutri-Sight Table OCR

OCR Layout Analysis Table Recognition

Extracting nutrition facts tables is critical for computing accurate Nutri-Score values. Nutri-Sight detects table boundaries, extracts numbers, and aligns row labels.

  • Handles multi-column tables, per-100g, and per-portion values
  • Interactive visual verification interface in our web components

NLP & Ingredient Parsing

NLP Vector Embeddings Taxonomy Matching

Ingredients lists are dense and multilingual. We use natural language processing and taxonomies to segment ingredients, identify additives, and flag allergens.

  • Detection of allergens (milk, gluten, nuts, soy, etc.)
  • Identification of ultra-processing markers for NOVA classification
