## Moet ik alle taalbestanden bijwerken wanneer ik een brontekst wijzig?

Nee, dat hoeft niet! Je hoeft alleen het Engelse bestand (`en`) aan te passen in je Pull Request. Zodra de PR is samengevoegd, zorgt ons geautomatiseerde Crowdin-vertaalsysteem via GitHub Actions voor de synchronisatie met alle overige talen.
